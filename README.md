# Radar-5.8Ghz
Some months ago, a drone intruded in my house, not once, but two times. I was scared, so I decided to build a DIY radar to detect drones near my home. P.S. the drone belongs to a neighborhood kid.

I searched a similar project, and I found this one: https://www.mdpi.com/2079-9292/10/22/2758#sec2-electronics-10-02758 Here I found in a simple way how a real radar works.

First, I want to familiarize with the management of the data this kind of project throw, so I started with an Arduino and a HC-SR04 ultrasonic sensor. Then I upgraded to a ESP32 WROOM and two HC-SR04.
